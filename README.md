# Ultrasonic Radar System

## 📌 Description
An Arduino-based radar system that detects obstacles and displays their position in real-time using a graphical interface.

## 🎯 Features
- 180° scanning using a servo motor  
- Real-time obstacle detection  
- Visual representation using Processing  
- Visualized scan results on-screen:
  - Red markers indicate detected obstacles  
  - Green areas represent clear space  
- Simple and low-cost design  

## 🛠️ Technologies Used
- Arduino
- Ultrasonic Sensor (HC-SR04)
- Servo Motor
- Processing

## ⚙️ How It Works
The ultrasonic sensor is mounted on a servo motor that rotates from 0° to 180°.  
It continuously measures distances and sends the data to the computer via serial communication.

The data is then visualized using Processing in real-time:
- Red markers represent detected obstacles  
- Green areas indicate clear space  

## 🔌 Components
- Arduino Board  
- Ultrasonic Sensor (HC-SR04)  
- Servo Motor  
- Jumper Wires  

## 🚀 How to Run
1. Upload the Arduino code using Arduino IDE  
2. Connect the components properly  
3. Run the Processing code  
4. Observe real-time radar visualization on screen
